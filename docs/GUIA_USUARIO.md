# Guía de Instalación — TelaryColor

Esta guía explica, paso a paso y sin conocimientos técnicos, cómo descargar,
instalar y actualizar **TelaryColor** en la computadora del área de pintura.
Solo necesita un navegador web (como Chrome, Edge o Firefox) y no hace falta
usar comandos ni herramientas especiales.

---

## 1. Descargar el instalador

Para obtener el instalador, siga estos pasos:

1. Abra su navegador web (Chrome, Edge o Firefox).
2. Vaya a la página de descargas de TelaryColor en esta dirección:

   `https://github.com/guigerdts/TelaryColor-Desktop/releases`

3. En esa página va a ver la lista de versiones publicadas. Busque la más
   reciente (es la que aparece primero).
4. Dentro de esa versión, busque el archivo que empieza con **`TelaryColor-Setup-`**
   y termina en **`.exe`** (por ejemplo: `TelaryColor-Setup-1.0.0.exe`).
5. Haga clic en el nombre del archivo `.exe` para descargarlo.
6. La descarga comienza automáticamente. El archivo se guarda en la carpeta
   **“Descargas”** (Downloads) de su computadora.

> No necesita saber nada de programación: la página de descargas es solo para
> obtener el archivo de instalación. Si no está seguro de qué archivo elegir,
> el que comienza con `TelaryColor-Setup-` es siempre el instalador.

---

## 2. Instalar TelaryColor

Una vez que el archivo terminó de descargarse:

1. Abra la carpeta **“Descargas”** de su computadora.
2. Busque el archivo `TelaryColor-Setup-...exe` que acaba de descargar.
3. Haga **doble clic** sobre el archivo para iniciar la instalación.

### La advertencia “Editor desconocido” (SmartScreen)

Es muy posible que Windows muestre una advertencia azul llamada
**“Editor desconocido”** (el mensaje completo dice que el editor de este
programa no se pudo comprobar). **Esto es normal y esperado** para
TelaryColor: el programa no está firmado digitalmente (no pagamos un
certificado de firma), por lo que Windows no puede confirmar automáticamente
quién lo creó. **Es seguro continuar.**

Para continuar con la instalación:

1. Haga clic en el texto **“Más información”** que aparece en la ventana de
   advertencia.
2. Aparecerá un botón nuevo con la opción **“Ejecutar de todas formas”**.
   Haga clic en ese botón.
3. La instalación continúa con normalidad.

> No se asuste por la advertencia: es el comportamiento habitual de Windows
> con programas que no tienen firma digital. El archivo es el instalador
> oficial de TelaryColor que usted mismo descargó desde la página oficial.

### Asistente de instalación

Después de superar la advertencia, se abre el asistente de instalación de
TelaryColor:

1. Haga clic en **“Siguiente”** (Next) para comenzar.
2. Elija la carpeta de instalación si lo desea (puede dejarla como está) y
   haga clic en **“Siguiente”** (Next).
3. Haga clic en **“Instalar”** (Install) para iniciar la instalación.
4. Cuando termine, haga clic en **“Finalizar”** (Finish).

TelaryColor quedará instalado y podrá abrirlo desde el acceso directo del
escritorio o del menú Inicio.

---

## 3. Actualizaciones

### Cómo se actualiza normalmente (automático)

TelaryColor se **actualiza automáticamente** la mayoría de las veces:

- Cada vez que abre la aplicación, TelaryColor verifica en segundo plano si
  hay una versión nueva disponible.
- Si existe una versión nueva, la aplicación lo notifica y se actualiza sola.

**Cómo sabe que hay una actualización:** al abrir el programa, si hay una
versión más reciente, TelaryColor muestra una notificación/aviso ofreciendo
actualizar. Con esa opción, no tiene que hacer nada más: la aplicación se
actualiza y se reinicia con la versión nueva.

### Actualización manual (si el automático no funciona)

Si por algún motivo la actualización automática no encuentra la versión nueva,
o si prefiere actualizar a mano, puede hacerlo descargando de nuevo el
instalador:

1. Siga los mismos pasos de la sección **“1. Descargar el instalador”** de
   esta guía (abrir la página de descargas y descargar el archivo
   `TelaryColor-Setup-...exe` más reciente).
2. Cierre TelaryColor si está abierto.
3. Instale sobre la versión anterior con el archivo descargado (pasos de la
   sección **“2. Instalar TelaryColor”**). El instalador reemplaza la versión
   anterior sin borrar sus datos.

**En resumen:** si las actualizaciones automáticas están funcionando, no hace
falta hacer nada. Si prefiere asegurarse o nota que no apareció una versión
nueva, descargue de nuevo el instalador desde la página de descargas e
instálelo. En ambos casos tendrá la versión más reciente de TelaryColor.
